# Presentación de defensa

Presentación base en LaTeX Beamer para la defensa del TFG.

## Compilar

Desde esta carpeta:

```bash
make
```

o manualmente:

```bash
pdflatex main.tex
pdflatex main.tex
```

## Archivo principal

- `main.tex`: contenido de las diapositivas.

Las figuras se cargan directamente desde `../results/`, por lo que la presentación debe compilarse desde la carpeta `slides/`.
